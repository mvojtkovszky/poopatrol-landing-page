# Poo Patrol — Landing Page

Static landing page for **Poo Patrol**, an app to track & analyze bowel movements, stool patterns, gut health & digestive habits.

The page links to the App Store and Google Play, shows platform-specific install banners on iOS and Android, and links to the privacy policy.

## Files

- `index.html` — landing page
- `privacy.html` — privacy policy (served at `/privacy`)
- `.htaccess` — URL rewrites (extensionless `/privacy`, root routing)
- `app-ads.txt` — authorized digital sellers declaration
- `appIcon.png` — app icon
